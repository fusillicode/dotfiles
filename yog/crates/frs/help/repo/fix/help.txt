Configure Rust workspaces and remove quarantine metadata.

Usage:
  frs repo fix [--clean] [--jobs N] DIRECTORY

Arguments:
  DIRECTORY                Rust repository directory to maintain.

Options:
  --clean                  Run `cargo clean` for every discovered Cargo workspace before setup.
  --jobs N                 Run at most N cargo and quarantine cleanup jobs at once (default: 7).

The command asks for confirmation before making changes.
